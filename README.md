# 小红书采集助手（社媒采集助手）

一个 Chrome / Edge 浏览器扩展（Manifest V3），专注**小红书**内容采集与素材下载：

- **关键词搜索采集**：按关键词自动采集小红书搜索结果的笔记数据，热度公式（点赞 + 收藏×1.5 + 评论×2）排行，历史快照对比，趋势/高频词分析。
- **素材库**：按关键词筛选、排序、勾选，导出 CSV。
- **在线解析下载**：勾选素材即自动把链接批量发给**多个第三方在线解析接口**（自动轮询切换：xhs-download.online 在线站 + wanyi-watermark 匿名 SSR 解析，哪个能用用哪个），解析出**无水印视频 + 封面 + 内页图**，按笔记标题分文件夹并发下载到「下载/小红书素材/标题/」。
- 采集数据保存在本浏览器本地（`chrome.storage.local`）；素材解析走在线接口/匿名抓取，**无需本地部署任何程序**，且**不占用你的小红书账号行为**。


## 安装（macOS 为例，其他系统相同）

1. 把本目录（`社媒采集助手`）解压/复制到任意位置（也可双击 `安装扩展.command` 自动复制并打开扩展页）。
2. 打开 Chrome（或 Edge），地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角「开发者模式」开关。
4. 点击「加载已解压的扩展程序」，选择本目录。
5. 工具栏出现 📕 图标，完成。

> 升级时请保留原扩展和原目录：用新版文件覆盖原目录，在扩展管理页点击「重新加载」，再刷新小红书页面。不要删除旧扩展，以免丢失采集数据。

## 使用

### 1. 关键词搜索采集（「采集」页）
- 输入关键词（逗号/换行分隔，逐个依次采集）。
- 可设置：排序、时间范围、每词上限、最低点赞/收藏/评论、采集间隔（防风控）。
- 点「▶ 开始搜索采集」：扩展逐个打开搜索页，自动滚动，达到上限或滚动无新内容后自动关闭并继续下一个。
- **必须先在小红书网页版登录**，否则页面无数据。

### 2. 素材库（「素材库」页）
- 按关键词筛选、按热度/点赞/收藏/评论/时间排序。
- 每条内容可「↗ 打开」；顶部可导出 CSV、清空素材。

### 3. 在线解析下载（「素材库」页）
- **勾选素材后点「▶ 解析下载勾选素材」开始**：插件**批量解析**（每次 5 篇一个请求，快很多）+ **本地并行打包**，不会自动触发。
- 解析来源按顺序自动尝试（哪个出结果用哪个）：
  1. **xhs-download.online** 批量解析接口（免登录、无需 API Key，5 篇/次）；
  2. **wanyi-watermark 匿名 SSR 解析**：直接抓笔记页 HTML 里的 `__INITIAL_STATE__` 提取无水印图片/视频直链（第三方开源项目的方式，不碰你的账号）；
  3. 兜底：下载库里已有的封面/素材。
- **每篇笔记打包成一个 zip**：图片由插件**并行抓取 + 本地打包**（不再等服务器逐张压图，速度提升数倍），zip 直接存到 `小红书素材/<笔记标题>.zip`；**视频单独下载**为 `标题_视频.mp4`。
- 本地打包失败时自动降级为服务器打包，再失败则逐文件下载，保证能拿到素材。
- **解析模式**（素材库工具栏可切换）：
  - **极速（SSR直连）**：插件匿名直连小红书页面解析，~1 秒/篇，不碰账号（默认）；
  - **稳妥（在线服务）**：解析请求走第三方在线服务服务器，~10 秒/篇，完全不占本地 IP。
- 素材库下方会显示进度（已处理/总数、失败数）和**成功接口名/失败原因**。
- 在线接口都取不到素材的笔记（如登录/权限保护、xsec_token 失效、已删除）会记为失败，可勾选重试。


### 4. 趋势 / 历史（「趋势/历史」页）
- 选择关键词点「刷新报告」：KPI 概览 + 高频关键词 Top15（TF-IDF）。
- 下方为采集历史。

## 风控与安全建议（重要）

任何自动化采集都违反平台规则，存在账号风控风险。请务必注意：

- **用专用小号**，不要用主号/有商业价值的账号采集。
- 把「采集间隔(秒)」调大（建议 10~30 秒），任务不要一次跑太多关键词。
- 账号要先正常使用一段时间（养号），新号尤其敏感。
- 不要在深夜无人值守时大批量连跑；分多次、低频进行。
- 本插件只拦截页面自身的请求，不会用你的 Cookie 主动批量发请求、不破解验证码；
  「在线解析下载」由第三方服务完成，不涉及你的账号。风险主要来自「采集开页频率 + 自动滚动」。

## 注意事项

- **必须已登录小红书网页版**，否则采集结果为 0。
- **小红书详情页必须带 `xsec_token` 才能打开**：从搜索采集入库的笔记会自动带上 token，
  点「↗ 打开」可正常进详情。
- 「每词上限」「最低点赞/收藏/评论」「时间范围」由插件强制生效：即使页面一次加载一整批，
  也只保留剩余额度内的内容；时间范围按笔记 ID 内嵌的发布时间二次过滤，超过范围的旧内容会被丢弃。
- 「在线解析下载」会把勾选素材的链接发送给第三方在线服务（xhs-download.online）；介意的话请勿使用该功能。
- 小红书不公开播放量，播放列显示 0。
- 请控制采集频率，避免账号被风控。
- 卸载扩展前如需保留数据，请先导出 CSV。

## 目录结构

```
社媒采集助手/
├── manifest.json    # 扩展清单（MV3，含主世界注入配置）
├── background.js    # 后台：入库去重 + 快照 + 搜索任务 + 在线解析下载并发协调
├── hook.js          # 注入小红书页面【主世界】的抓取钩子（拦截搜索接口）
├── content.js       # 隔离世界：会话管理 + 自动滚动 + 数据转发
├── trend.js         # 趋势分析纯函数（中文分词 + TF-IDF）
├── popup.html/css/js# 弹窗界面：采集、素材库、趋势/历史
├── icons/           # 图标
└── 安装扩展.command  # 一键安装辅助脚本
```

> 技术说明：普通内容脚本运行在「隔离世界」，改写页面里的 fetch/XHR 拦不到页面自身请求。
> 本插件把抓取钩子 `hook.js` 注入页面主世界（`world: "MAIN"`，Chrome 111+ 支持），
> 抓到的数据再通过 postMessage 传给隔离世界的 `content.js` 转发后台，
> 因此能真正捕获小红书搜索接口的返回数据。
> 素材下载不再由插件自己解析，而是调用第三方在线去水印服务的公开接口批量解析。

### 测试方法
1. 更新扩展并刷新小红书，登录账号。
2. 先采集 1—3 篇笔记，在素材库打开其中一篇有正文的笔记，等正文显示。
3. 保持笔记标签页打开，返回扩展导出 Excel，检查正文列。
4. 对没有打开或不可访问的笔记，检查是否明确提示正文仍为空。

搜索结果可能没有完整正文。后台请求也可能遇到登录或验证，不能保证匿名批量补齐。此版本不自动处理验证，不自动打开大量详情页。图片下载仍可能向第三方解析服务发送笔记链接。
